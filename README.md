# До зарплаты

Мини-приложение: сколько можно потратить сегодня, чтобы дотянуть до зарплаты и закрыть долг.

Это одна статическая страница. Сервера и базы данных нет.

## Где хранятся данные

- **Внутри Telegram** — в облаке Telegram (CloudStorage), отдельно для каждого пользователя и бота. Синхронизируются между устройствами пользователя.
- **В обычном браузере** — только в памяти этого браузера.

В репозитории данных пользователей нет.

## Файлы

- `index.html` — приложение целиком, его открывают GitHub Pages и Telegram.
- `manifest.webmanifest`, `icon.svg` — название и иконка для экрана телефона.

## Запуск

1. Включить GitHub Pages для ветки `main`, папка `/`.
2. В Telegram у @BotFather: `/newbot`, затем `/setmenubutton` и адрес страницы на GitHub Pages.
3. Открыть бота и нажать кнопку меню.

Токен бота для этого не нужен: он понадобится только когда появится серверная часть (напоминания, запись трат сообщением).

## Безопасность

- Имя и фото из профиля Telegram считаются недоверенными: имя очищается и выводится только как текст, фото принимается только по https с адресов Telegram.
- Все данные из облака, браузера и файлов проходят проверку перед использованием.
- Страница может загружать только свои файлы, скрипт Telegram, шрифты Google, аватарки Telegram и курсы ЦБ (правило Content-Security-Policy в `index.html`).
- Данные о пользователе из Telegram на клиенте не проверены подписью. Пока сервера нет, это влияет только на отображаемое имя. При появлении сервера подпись `initData` нужно проверять на нём токеном бота.
